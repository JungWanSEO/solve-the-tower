# Solve the Tower

수학 선생 친구를 위한 슬더슬 같은 수학게임

수학을 포기했던 주인공이 문제를 풀어 몬스터와 싸우며 수학의 탑을 오르는 스마트폰용 로그라이크 웹 게임입니다. 갈림길 지도에서 길을 골라 보스까지 올라가고, 쓰러지면 처음부터 다시 시작합니다.

이 문서는 사용설명서처럼 위에서부터 순서대로 따라 하면 되도록 썼습니다. 여기에는 소개와 실행 방법만 있고, 자세한 내용은 [더 읽을 문서](#더-읽을-문서)의 네 문서에 나눠 두었습니다.

## 2. 실행해 보기

파일을 더블클릭해서 열면 동작하지 않습니다. 브라우저가 보안상 데이터 파일을 읽지 못하게 막기 때문입니다. 아래 둘 중 하나로 실행합니다.

**내 컴퓨터에서**

1. 이 폴더에서 터미널을 엽니다.
2. `python -m http.server 8000` 을 실행합니다. (VS Code의 Live Server 확장도 됩니다.)
3. 브라우저에서 `http://localhost:8000` 을 엽니다.

**스마트폰에서 (GitHub Pages)**

1. 저장소의 Settings → Pages 로 갑니다.
2. Source 를 "Deploy from a branch" 로 두고 브랜치와 `/ (root)` 를 고른 뒤 Save 를 누릅니다.
3. 잠시 뒤 `https://<계정>.github.io/solve-the-tower/` 로 접속합니다.

개발 중에는 `dev` 브랜치를, 정식 배포 뒤에는 `main` 브랜치를 보게 합니다.

**처음부터 다시 해 보고 싶을 때**

진행 기록은 서버가 아니라 이 기기의 브라우저에만 저장됩니다. **설정 → 데이터 관리**에서 다음을 할 수 있습니다.

| 기능 | 하는 일 |
| --- | --- |
| 저장된 용량 보기 | 진행 기록과 오프라인용 파일이 각각 얼마나 차지하는지 |
| 기록 내보내기 | 기록을 글자 코드(`STT1-…`)로 만들어 복사하거나 파일로 저장 |
| 기록 가져오기 | 코드를 붙여 넣거나 파일에서 읽어 복원. 다른 기기나 홈 화면 앱으로 옮길 때 사용 |
| 기록 초기화 | 진행 기록과 도감만 지움. 언어와 소리 설정은 남음 |
| 모두 지우기 | 기록, 오프라인용 파일, 서비스 워커 등록까지 이 기기에서 전부 지움 |

지우기 전에는 무엇이 사라지는지 보여 주는 확인 창이 뜨고, "먼저 기록 내보내기"를 고를 수 있습니다.

**아이폰에서 기록이 사라질 수 있습니다.** 사파리는 사파리를 쓴 날로 7일 동안 들르지 않은 사이트의 저장 데이터를 자동으로 지웁니다. 홈 화면에 추가한 앱은 지워지지 않습니다. 그래서 아이폰 사파리로 열면 처음 화면에 안내가 나오고, 데이터 관리 화면에 홈 화면 추가 방법이 있습니다. 사파리에서 하던 기록을 홈 화면 앱으로 옮길 때는 내보내기 → 가져오기를 씁니다.

백업 코드는 `js/save.js` 의 `encodeSave` / `decodeSave` 가 만들고 읽습니다. 읽을 때는 모양이 맞는 값만 받아들이고 나머지는 기본값으로 둡니다.

튜토리얼은 처음 하는 사람에게 한 번만 나옵니다. 화면을 어둡게 가리고 눌러야 할 곳만 밝게 보여 주며, 화살표 달린 말풍선으로 설명합니다.

- 10단계입니다: 출발 칸 → 적의 체력과 약점 → 다음 턴 예고 → 내 체력과 필살기 → 기본 공격 → 스킬 → 강한 공격 예고 → 방어 → 강화 고르기 → 다음 칸. 필살기와 연속기는 처음 쓸 수 있게 됐을 때 따로 한 번 알려 줍니다.
- 튜토리얼의 세 문제(기본 공격, 스킬, 방어)는 **정답을 알려 줍니다.** 정답이 노랗게 빛나고 다른 답은 누를 수 없습니다. 조작을 배우는 자리라, 틀려서 흐름이 어긋나지 않게 한 것입니다. 그 뒤 "자유롭게 싸우기"부터는 평소처럼 풉니다.
- 전투 도중에 건너뛰면 그 연습 전투를 끝내고 **지도로 돌아가** 체력이 가득 찬 상태로 처음부터 시작합니다.
- 말풍선의 **건너뛰기**로 언제든 끝낼 수 있습니다. 한 번 끝내거나 건너뛰면 새 지도를 시작해도 다시 나오지 않습니다.
- 다시 보고 싶으면 처음 화면의 **튜토리얼 다시 보기**를 누릅니다. (튜토리얼을 끝낸 뒤에만 보입니다)
- 문제를 푸는 동안에는 화면을 가리지 않고 위쪽 노란 줄에 한 문장만 나옵니다.

단계와 문구는 `js/tutorial.js` 의 `GUIDES` 에서 고칩니다. 강조할 곳은 CSS 선택자로 적고, 위치는 `js/guide.js` 가 화면에서 직접 재므로 화면 크기가 달라도 어긋나지 않습니다.
