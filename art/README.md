# 그림 바꾸기 설명서 (直接かいた絵に入れかえる)

게임에 나오는 주인공, 몬스터, 장면 그림을 **직접 그린 그림 파일로 바꾸는 방법**입니다. 그림을 넣지 않은 것은 지금처럼 도형 그림이 나옵니다. 한 장씩 바꿔도 되고, 다 바꾸지 않아도 됩니다.

## 1. 한눈에 보기

| 하고 싶은 일 | 할 일 |
| --- | --- |
| 몬스터 한 마리를 내 그림으로 | `art/monsters/` 에 그림을 넣고 `art/art.json` 의 `monsters` 에 한 줄 추가 |
| 주인공을 내 그림으로 | `art/` 에 그림을 넣고 `art.json` 의 `hero` 에 파일 이름 |
| 상점·휴식 같은 장면 그림을 바꾸기 | `art/scenes/` 에 그림을 넣고 `art.json` 의 `scenes` 에 한 줄 추가 |
| 원래 그림으로 되돌리기 | `art.json` 에서 그 줄을 지움 |

코드는 고치지 않습니다. 그림 파일과 `art.json` 만 바꿉니다.

## 2. 그리는 사람에게 전할 것 (絵をかく人へ)

| 項目 / 항목 | きまり / 규칙 |
| --- | --- |
| 大きさ / 크기 | 512 × 512 px (정사각형). 더 커도 되지만 가로세로 비율은 그림 그대로 나옵니다 |
| ファイル / 파일 형식 | PNG, **背景は透明 / 배경은 투명** |
| 向き / 방향 | モンスターは左向き、主人公は右向き / 몬스터는 왼쪽, 주인공은 오른쪽을 봄 |
| 足もと / 발밑 | 그림의 아래쪽 끝이 땅에 닿습니다. 아래 여백을 많이 남기면 공중에 뜬 것처럼 보입니다 |
| 線と色 / 선과 색 | 배경이 어두운 남색(#14224a)이므로 **밝은 색**이 잘 보입니다. 검은 선만으로 그린 그림은 잘 안 보입니다 |
| 文字 / 글자 | 몬스터 몸에 글자를 넣을 때는 큼직하게. 화면에서는 약 120px 높이로 줄어듭니다 |
| 影 / 그림자 | 그리지 않습니다. 게임이 바닥 그림자를 따로 그립니다 |

- 틀: `template-monster.png`, `template-hero.png` 위에 그리면 크기와 방향을 맞추기 쉽습니다. (틀의 선은 완성본에서 지워 주세요)
- 참고 그림: `reference/` 에 지금 게임의 주인공과 몬스터 22장이 들어 있습니다. "이 캐릭터를 내 방식으로 다시 그린다"고 생각하면 됩니다. 몬스터가 뜻하는 실수(아래 표)가 드러나면 더 좋습니다.
- 움직임은 게임이 붙입니다. 가만히 있을 때의 흔들림, 공격할 때 앞으로 나가기, 맞았을 때 번쩍이며 떨기, 쓰러질 때 납작해지며 사라지기가 그림 한 장에 자동으로 적용됩니다. **그림은 한 장이면 됩니다.**
- 저작권: 직접 그린 그림만 넣습니다. 다른 만화·게임의 캐릭터를 따라 그린 그림은 넣을 수 없습니다.

## 3. 넣는 순서

1. 그림 파일을 넣습니다. 예: `art/monsters/slime.png`
2. `art/art.json` 을 엽니다. 몬스터 id(아래 표)와 파일 이름을 적습니다.

   ```json
   {
     "hero": "hero.png",
     "monsters": {
       "slime": "monsters/slime.png",
       "dragon": { "file": "monsters/dragon.png", "scale": 1.2, "dy": 4 }
     },
     "scenes": {
       "shop": "scenes/shop.png"
     }
   }
   ```

3. 게임을 새로 고칩니다. 전투, 도감에 그 그림이 나옵니다.
4. 올릴 때는 `sw.js` 의 `VERSION` 을 바꿉니다. (바꾸지 않으면 이미 열어 본 사람에게 예전 그림이 나옵니다)

| `art.json` 에 적는 값 | 뜻 |
| --- | --- |
| `"파일 이름"` | 그 그림을 그대로 씀 |
| `"file"` | 그림 파일 (art 폴더 기준) |
| `"scale"` | 크기 배율. 1 이 기본(높이 약 124), 보스는 1.2 쯤이 어울립니다 |
| `"dy"` | 세로 위치 조정. 숫자가 클수록 아래로. 공중에 떠 보이면 올립니다 |

## 5. 장면 그림 이름

| 이름 | 나오는 곳 | 권장 크기 |
| --- | --- | --- |
| `title` | 처음 화면의 탑 그림 | 1080 × 510 (가로로 긴 그림) |
| `shop` `rest` `treasure` | 상점, 휴식, 보물 | 1080 × 390 |
| `reward` `over` `clear` `bless` | 승리, 게임 오버, 탑 클리어, 탑지기의 선물 | 1080 × 390 |
| `spring` `fog` `purse` `thief` `note` `statue` `ambush` | ? 칸의 사건 일곱 가지 | 1080 × 390 |

장면 그림은 배경이 투명하지 않아도 됩니다. 화면 폭에 맞춰 가운데를 기준으로 잘려 보이므로, 중요한 것은 가운데에 그립니다.

## 6. 자주 묻는 질문

- **그림이 안 나와요.** 파일 이름의 대소문자와 확장자(.png)가 `art.json` 과 같은지 확인합니다. 그림을 못 찾으면 게임은 멈추지 않고 원래 도형 그림을 보여 줍니다.
- **그림이 너무 작게/크게 나와요.** `scale` 을 바꿉니다.
- **그림이 공중에 떠 있어요.** 그림 아래쪽의 투명한 여백을 잘라 내거나 `dy` 를 키웁니다.
- **참고 그림을 다시 뽑고 싶어요.** `tools/export-art.mjs` 를 돌립니다.
