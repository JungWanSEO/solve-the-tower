# 게임 방법

처음 화면부터 지도, 전투, 유물, 다시 도전할 때의 선물·격려·도전 단계까지, 게임을 하는 사람이 보는 순서대로 설명합니다.

[← 처음 문서(README)로 돌아가기](../README.md)

## 3. 게임 방법

### 처음 화면

- **이어서 하기**: 진행 중인 지도가 있으면 나옵니다. 하던 곳에서 계속합니다.
- **시작하기 / 처음부터 다시**: 범위를 고르고 새 지도에서 출발합니다. 진행 중인 지도가 있으면 확인 창이 뜨고, **지우고 새로 시작** 을 눌러야 지워집니다.
- **도감 / 튜토리얼 / 설정**: 큰 버튼 아래의 작은 버튼 줄입니다. 도감은 유형별 기록(단원별 정복 막대)과 만난 몬스터(얼굴 그림 포함), 튜토리얼은 다시 보기(한 번 끝낸 뒤에만 보임)입니다.
- 맨 위에는 탑 그림과 제목이, 그 아래에는 지금까지의 기록(이긴 전투, 탑 클리어)이 한 줄로 나옵니다.
- **설정**: 처음 화면의 작은 버튼 줄과 게임 중 메뉴에서 엽니다. 바꾸면 바로 적용되고 이 기기에 저장됩니다.

  | 묶음 | 항목 | 하는 일 |
  | --- | --- | --- |
  | 소리 | 음악, 효과음 | 막대로 음량을 따로 조절. 맨 왼쪽이면 꺼짐 |
  | 화면 | 언어 | 日本語 / 한국어 / English |
  | 화면 | 큰 글씨 | 문제와 답의 글자를 16px → 19px 로 (약 1.2배). 답 버튼 높이도 52 → 58px. 이때는 그림을 덜 줄이는 대신, 작은 폰에서는 조금 스크롤할 수 있음 |
  | 화면 | 연출 줄이기 | 흔들림, 반짝임, 화면 전환 효과를 끔 (기기의 "동작 줄이기"와 같은 효과) |
  | 게임 | 격려 받기 | 끄면 연달아 쓰러져도 도움이 붙지 않음 |
  | 게임 | 데이터 관리 | 백업, 홈 화면 안내, 지우기 화면으로 이동 |

  음악은 장면에 따라 바뀝니다. 곡은 `js/sound.js` 의 `TRACKS` 에 악보(화음·가락·베이스·북)로 적혀 있습니다.

  | 장면 | 곡 | 느낌 |
  |---|---|---|
  | 지도·상점·휴식 | `calm` | 잔잔하게 |
  | 보통 전투 | `battle` · `battleA` · `battle2` | 몬스터의 약점 단원이 数学I · 数学A · 数学II 중 어디인지로 고름 |
  | 강적 | `elite` | 쉬지 않고 몰아치는 베이스 |
  | 중간 보스 | `midboss` | 빠르고 긴장감 있게 |
  | 보스 | `boss` | 느리고 웅장하게. 보스마다 조(음 높이)가 다름 |

  설정은 `js/settings.js` 가 맡고, 값은 저장 기록의 `opt` 에 들어갑니다. 소리는 파일 없이 `js/sound.js` 가 직접 만듭니다. `SOUNDS` 표를 고치면 효과음이, `TRACKS` 표(빠르기, 화음 진행, 짚는 순서)를 고치면 음악이 바뀝니다. 음악은 세 곡입니다: 지도·상점 등(`calm`), 전투(`battle`), 중간 보스·보스(`boss`).
- **메뉴**: 게임 중 어느 화면에서나 위쪽 **메뉴** 버튼(또는 스마트폰의 뒤로 버튼, 키보드 Esc)으로 잠시 멈춥니다. **계속하기** 와 **처음 화면으로 나가기** 가 있습니다. 전투 도중에 나가면 그 전투는 처음부터 다시 하고, 체력과 힌트는 그대로 저장됩니다.

### 범위 고르기

새 지도를 시작할 때마다 이번 판에 나올 문제 유형을 고릅니다.

- 단원은 접혀 있습니다. 단원 줄을 누르면 유형 목록이 펼쳐지고, 옆의 **모두 고르기 / 모두 빼기** 로 단원을 통째로 넣거나 뺄 수 있습니다. 줄 왼쪽의 색은 전부 고름(초록), 일부만 고름(노랑), 안 고름(회색)입니다.
- 유형마다 정답률과 정복 여부가 보입니다. 부족한 유형만 골라 집중할 수 있습니다.
- **전체**, **미정복만**, **지난번과 같게** 버튼으로 빠르게 고를 수 있습니다.
- 유형을 하나 더 넣을 때마다 전투 골드가 5%씩 늘어납니다. (최대 50%)
- 고른 범위에 어려운 단계의 문제가 없으면 가장 가까운 단계의 문제가 대신 나옵니다.
- 적의 약점 유형도 고른 범위 안에서 정해집니다.
- 아래쪽에 이 범위에서 쓸 수 있는 **연속기 묶음 수**가 나옵니다. 연속기는 한 묶음의 유형을 모두 골라야 나옵니다.

### 지도

1. 지도는 탑의 안쪽을 그린 것으로, 10층입니다. 맨 아래 **입구**에서 출발할 칸을 고르고, 맨 위의 보스까지 올라갑니다.
2. 길로 이어진 칸으로만 갈 수 있습니다. 어느 길로 갈지는 직접 정합니다.
3. 5층에는 중간 보스가 있고, 그 바로 아래 층(4층)에는 휴식 칸이 적어도 하나 있습니다. 중간 보스 방에 들어갈 때는 방 앞의 샘에서 체력을 8 회복합니다(한 번만). 보스 바로 아래 층은 항상 휴식입니다. 1~2층의 보통 전투는 적의 체력이 낮습니다(몸풀기).
4. 지도는 시작할 때마다 새로 만들어집니다.

**지도 읽는 법**

| 보이는 것 | 뜻 |
| --- | --- |
| 노랗게 반짝이는 칸, 흐르는 노란 점선 | 지금 갈 수 있는 칸과 길 |
| 초록 칸, 초록 실선 | 지나온 칸과 길 |
| 흐린 칸, 옅은 점선 | 아직 갈 수 없는 칸과 길 |
| 초록 핀 | 내가 지금 있는 곳. 칸을 누르면 핀이 길을 따라 움직인 뒤 그 칸으로 들어갑니다 |
| 맨 위의 글 | 큰 글씨는 지금 몇 층인지, 작은 글씨는 이번 판의 범위 |
| 위쪽의 칩 | 체력, 골드, 힌트. 그 옆의 색 딱지는 지금 걸려 있는 효과(도전, 격려, 약해진 적)이고, 누르면 설명이 나옵니다 |
| 왼쪽의 1F ~ 10F | 층 번호. 붉게 물든 층은 중간 보스와 보스 |
| 제목 아래의 막대 | 몇 층까지 올라왔는지 |
| 지도 아래의 "칸 설명 보기" | 칸 종류 설명. 처음 몇 판은 펼쳐져 있고, 그 뒤로는 접혀 있습니다 |

| 칸 | 무슨 일이 생기나 |
| --- | --- |
| 전투 | 몬스터와 싸웁니다. 이기면 골드를 받고 강화를 하나 고릅니다. |
| 강적 | 체력과 공격이 더 센 몬스터입니다. 골드를 더 줍니다. |
| ? | 무슨 일이 생길지 모릅니다. 아래 표를 봅니다. |
| 보물 | 문제를 맞히면 골드와 힌트를 얻습니다. |
| 상점 | 골드로 강화를 삽니다. |
| 휴식 | 체력을 회복하거나, 틀렸던 유형을 복습해 힌트를 얻습니다. |
| 중간 보스 | 반드시 지나가는 강한 적입니다. |
| 보스 | 응용 문제를 냅니다. 이기면 단원 클리어입니다. |

**? 칸에서 생기는 일** (열네 가지 중 하나가 무작위로 나옵니다. 골드나 체력이 모자라 아무것도 할 수 없는 사건은 나오지 않습니다)

| 사건 | 결과 |
| --- | --- |
| 맑은 샘물 | 체력 회복 |
| 측량사의 쪽지 | 힌트 +1 |
| 떨어진 지갑 | 골드 획득 |
| 짙은 안개 | 체력 감소 (1 아래로는 내려가지 않음) |
| 소매치기 | 골드 감소 |
| 수상한 석상 | 도전하면 어려운 문제. 맞히면 강화, 틀리면 체력 감소. 지나칠 수도 있음 |
| 기습 | 전투가 시작됨 |
| 약점 쪽지 | 다음 전투에서 처음 3번의 공격 문제가 적의 약점 유형으로 나옴 |
| 낡은 칠판 | 어려운 문제. 맞히면 힌트 +2, 틀려도 잃는 것은 없음. 지나칠 수도 있음 |
| 내기꾼 | 20G 를 걸고 어려운 문제. 맞히면 건 돈을 돌려받고 +40G, 틀리면 건 돈을 잃음. 지나칠 수도 있음 |
| 수련장 | 체력 5 를 내고 강화 셋 중 하나를 고름. 지나칠 수도 있음 |
| 떠돌이 상인 | 흔한 유물 하나를 40G 에 삼 (상점에서는 80G). 지나칠 수도 있음 |
| 잊힌 사물함 | 가진 유물 하나를 넣으면 같은 등급의 다른 유물이 나옴. 무엇이 나올지는 모름. 지나칠 수도 있음 |
| 쉬어 가는 벤치 | 체력 +4 와 최대 체력 +2 중 하나를 고름 |

나쁜 일(짙은 안개, 소매치기, 기습)은 다른 사건보다 두 배 자주 나옵니다. 숫자와 비중은 `js/config.js` 의 `mystery` 에 있습니다.

### 전투

**화면 읽는 법**

| 보이는 것 | 뜻 |
| --- | --- |
| 맨 위의 붉은 줄 | 적의 체력. 깎이면 흰 줄이 잠깐 남아서 방금 준 피해가 보입니다 |
| 노란 이름표 | 적의 약점 유형 |
| 싸우는 그림 | 주인공과 적. 맞히면 베는 자국과 피해 숫자가 튀어나오고, 약점을 찌르면 "약점!"이 함께 뜹니다 |
| 그림 아래의 알약 모양 글 | 적의 다음 턴 예고. 강한 공격이면 붉게 깜빡입니다 |
| 버튼의 색 딱지 | 그 행동으로 문제를 맞혔을 때의 피해 (강화하면 숫자가 늘어납니다) |
| 필살기 버튼 | 연속 정답만큼 노랗게 차오르고, 다 차면 빛납니다 |
| 노랗게 빛나는 버튼과 "맞히면 쓰러뜨림" | 그 행동의 피해가 적의 남은 체력 이상일 때. 쓰러뜨리면 적의 공격(강한 공격 포함)은 오지 않으므로, 강한 공격 턴에도 방어 대신 끝낼 수 있습니다. 약점 보너스는 셈에 넣지 않은 확실한 경우만 표시합니다 |
| 적이 쓰러질 때 | 화면이 번쩍이고 "격파!"가 뜹니다. 중간 보스와 보스는 여러 번 터집니다. 탑을 깨면 색종이가 쏟아집니다 |
| 위에서 내려오는 노란 알림 | 강화나 선물을 고르거나 상점에서 샀을 때, 무엇을 얻었는지 잠깐 알려 줍니다 |

상점·휴식·보물·? 칸과 승리·패배·클리어 화면에는 위쪽에 그 장면의 그림이 나옵니다. 그림과 아이콘은 모두 `js/art.js` 에 SVG 로 들어 있어, 그림 파일을 따로 받지 않습니다.

1. 적의 "다음 턴 예고"를 봅니다.
2. 행동을 고릅니다.
   - **기본 공격**: 쉬운 문제가 나옵니다. 맞히면 약한 피해를 줍니다.
   - **스킬**: 어려운 문제가 나옵니다. 맞히면 큰 피해를 줍니다.
   - **연속기**: 한 상황에서 물음 (1), (2), (3)을 이어 풉니다. 맞힐 때마다 피해 2 → 3 → 6을 주고, 틀리면 거기서 끝나 적의 공격을 받습니다. 한 전투에 한 번만 쓸 수 있습니다. 이번 범위에 풀 수 있는 묶음이 없으면 버튼이 보이지 않습니다.
   - **방어**: 쉬운 문제가 나옵니다. 맞히면 피해를 받지 않고 반격합니다. 틀리면 피해를 절반 받습니다. 연속으로는 쓸 수 없습니다.
3. 문제가 나오면 답을 고릅니다. 시간 제한은 없습니다.
4. 맞히면 적의 보통 공격을 받지 않습니다. 틀리면 공격이 빗나가고 적의 공격을 받으며, 해설이 나옵니다. 틀린 문제는 답 바로 아래에 **정답과 풀이 카드**가 뜨고, **확인했어요, 다음** 을 눌러야 넘어갑니다.
5. 3문제를 연속으로 맞히면 필살기를 쓸 수 있습니다. 틀리면 게이지가 0이 됩니다.
6. 적의 약점 유형 문제를 맞히면 피해가 1.5배입니다.
7. **강한 공격**(3턴마다, 붉은 예고)은 문제를 맞혀도 맞습니다. 방어로만 막을 수 있습니다.
8. 힌트를 쓰면 틀린 보기 하나가 지워집니다.
9. 틀린 직후에 메뉴로 나가도 받기로 된 피해는 받습니다. 보물 상자, 휴식, 석상은 한 번 문제를 보거나 쓰면 나갔다 와도 다시 할 수 없습니다.
10. 체력이 0이 되면 게임 오버입니다. 골드와 강화는 사라지고, 새 지도로 처음부터 다시 시작합니다. 도감 기록은 남습니다.

적은 3턴마다 강한 공격을 합니다. 강한 공격은 공격 문제를 맞혀도 피할 수 없고 방어로만 막을 수 있습니다. 예고를 보고 그 턴에 방어하는 것이 요령입니다.

### 모습 (직업)

주인공은 수학을 포기했던 아이입니다. 탑을 깰 때마다 성장해서 **새 모습**을 얻고, 새 판을 시작할 때 얻은 모습 중 하나를 고릅니다.

| 모습 | 얻는 때 | 체력 | 고유 능력 | 시작 유물 | 그림 |
|---|---|---|---|---|---|
| 다시 시작한 아이 | 처음부터 | 30 | 없음. 기본 규칙 그대로 | 닳은 연필 | 주황 모자, 초록 옷, 지팡이와 각도기 |
| 끈기 대장 | 탑을 1번 깨면 | 34 | 방어에 성공하면 다음 정답의 피해 +2 | 삼각자 | 붉은 머리띠, 남색 옷, 삼각자 방패 |
| 암산 번개 | 탑을 2번 깨면 | 24 | 필살기에 필요한 연속 정답 2개 (원래 3개) | 책갈피 | 노란 목도리, 보라 옷, 번개 분필 |

**새 판을 시작하는 순서**

1. 범위를 고릅니다.
2. 과목을 둘 이상 골랐으면 탑의 길이를 고릅니다.
3. 모습을 고릅니다. 아직 얻지 못한 모습은 그림자와 "탑을 1번 깨면 얻습니다"가 보입니다. 얻은 모습이 하나뿐이면 이 화면은 건너뜁니다.
4. 지도가 열립니다.

**새 모습을 얻었을 때**: 탑을 깬 뒤 다음 판을 시작하려고 하면 "새 모습을 얻었습니다" 창이 한 번 뜹니다. 그림, 이름, 성장 이야기 한 줄, 고유 능력, 시작 유물이 나옵니다. 이미 탑을 깬 기록이 있으면 업데이트 뒤 처음 시작할 때 뜹니다.

- 행동 버튼(기본 공격·스킬·방어·연속기·필살기)은 세 모습이 같습니다.
- 튜토리얼은 첫 모습으로만 합니다. 도전 단계, 격려, 재도전 선물은 세 모습에 똑같이 적용됩니다.
- 가방 창의 맨 위에 지금 모습과 고유 능력이 나옵니다.
- 얻었는지는 탑을 깬 횟수로 판단합니다. 숫자는 `js/config.js` 의 `hero`, 이름과 설명은 `lang/` 의 `hero.<id>`, 그림은 `js/stage.js` 의 `drawHero`(전투)와 `js/art.js` 의 `heroBody`(장면·초상)에 있습니다.
- 모습 하나만으로 밸런스를 잴 때: `TUNE='{"config":{"hero":{"force":"grit"}}}' node tools/balance.mjs`

### 진보스와 열쇠

탑을 한 번 깬 뒤부터는 **열쇠**가 나옵니다. 한 판 동안 열쇠 셋을 모으면, 마지막 보스를 이긴 뒤 진보스 **포기의 그림자**에게 도전할 수 있습니다.

**열쇠는 보상을 포기하고 얻습니다**

| 열쇠 | 얻는 곳 | 포기하는 것 |
|---|---|---|
| 쉼의 열쇠 | 휴식 칸 | 쉬기와 복습 (그 칸에서는 열쇠만 받음) |
| 보물의 열쇠 | 강적 또는 보물 상자 | 거기서 받을 유물 1개. "유물과 열쇠" 화면에서 하나를 고름 |
| 승리의 열쇠 | 중간 보스 | 유물 3개 중 1개 고르기 |

- 상태 줄에 열쇠 그림과 "1/3" 같은 수가 나옵니다. 누르면 어느 열쇠를 어디서 얻는지 나옵니다.
- 이미 가진 열쇠는 다시 나오지 않습니다. 긴 탑에서는 열쇠를 다음 막으로 가져갑니다.
- 튜토리얼 중이거나 아직 탑을 깬 적이 없으면 열쇠는 나오지 않습니다.

**진보스와 싸우는 순서**

1. 열쇠 셋을 가진 채 마지막 보스를 이기면 "세 열쇠가 빛납니다" 창이 뜹니다.
2. "문을 연다"를 누르면 체력을 12 회복하고 진보스와 싸웁니다. "돌아간다"를 누르면 그대로 탑 클리어입니다.
3. 진보스의 문제는 고른 범위 전체에서 나옵니다. 규칙은 보스전과 같습니다(보스 전용 연속기, 도전 6단계의 칸 채우기).
4. 이기면 "진보스 격파" 횟수가 기록됩니다. **져도 탑을 깬 기록은 그대로입니다.**

숫자는 `js/config.js` 의 `trueBoss`, 진보스는 `data/monsters.json` 에서 `"final": true` 인 몬스터(체력 44), 글은 `lang/` 의 `key` 에 있습니다. 봇으로 진보스까지 가 보려면 `KEYS=1 node tools/play.mjs 0.9 4 '<탑을 깬 기록이 있는 저장>'` 을 씁니다.

### 유물

유물은 한 번 얻으면 그 판이 끝날 때까지 **저절로 작동하는 아이템**입니다. 누르거나 켜는 조작은 없습니다.

**규칙**

1. 개수 제한이 없습니다. 얻은 유물은 모두 가집니다.
2. 같은 유물은 한 판에 한 번만 나옵니다.
3. 쓰러지거나 탑을 깨면 사라집니다. 긴 탑에서는 다음 막으로 가져갑니다.
4. 유물은 수학을 대신 풀어 주지 않습니다. 맞혔을 때의 보상과 틀렸을 때의 손해만 바꿉니다.

**얻는 곳**

| 곳 | 받는 방식 | 나오는 등급 |
|---|---|---|
| 보물 상자 | 문제를 맞히면 1개 (골드 30과 함께) | 흔함 2 : 드묾 1 |
| 강적 | 이기면 1개. 보상 화면 위에 "유물을 얻었습니다" 카드로 나옴 | 흔함 2 : 드묾 1 |
| 중간 보스 | 강화를 고른 뒤 3개 중 1개 고르기. "받지 않기" 가능 | 드묾과 보스 등급 |
| 막을 넘어갈 때 (긴 탑) | 3개 중 1개 고르기 | 드묾과 보스 등급 |
| 상점 | 유물 칸 1개 (흔함 80G, 드묾 120G) | 흔함 2 : 드묾 1 |

줄 유물이 남아 있지 않으면 골드 40을 대신 받습니다. 튜토리얼 중의 강적·중간 보스는 유물을 주지 않습니다.

**보는 곳**

- **유물 줄**: 체력·골드·힌트 칩이 있는 줄의 오른쪽에 아이콘이 얻은 순서대로 놓입니다. 4개까지 보이고, 넘으면 아이콘 3개와 "+N"이 됩니다. 줄은 늘 한 줄이라 문제 화면의 높이는 변하지 않습니다.
- **가방**: 유물 줄을 누르면 열립니다. 유물마다 이름, 등급, 효과(숫자 포함), 지금 상태("이번 전투: 사용함", "연속 정답 2/3")가 글로 나옵니다. 아이콘만 보고 뜻을 알아야 하는 화면은 없습니다.
- **효과가 났을 때**: 화면 아래에 "닳은 연필 · 피해 +2"처럼 잠깐 알림이 뜨고, 유물 줄의 그 아이콘이 한 번 커졌다 돌아옵니다. ("차분한 화면" 설정에서는 글만)
- **도감**: "유물" 탭에 한 번이라도 얻어 본 유물이 기록됩니다.

### 다시 도전할 때: 선물, 격려, 도전 단계

한 판이 끝나면(쓰러지든 깨든) 다음 판은 조금 다르게 시작합니다. 못 깬 사람은 점점 쉬워지고, 깬 사람은 더 어려운 규칙을 고를 수 있습니다.

| 이름 | 언제 | 무엇을 |
| --- | --- | --- |
| 탑지기의 선물 | 두 번째 판부터, 범위를 고른 직후 | 지난 판에 5층 이하에서 쓰러졌으면 **최대 체력 +6** 또는 **처음 3번의 전투에서 적 체력 1** 중 하나. 더 올라갔거나 깼으면 골드 +40, 힌트 +2, 최대 체력 +4, 기본 공격 +1, 스킬 +1 중 셋이 나와 하나를 고름 |
| 격려 | 탑을 깨지 못하고 연달아 쓰러질 때마다 한 단계 (최대 5) | 단계마다 최대 체력 +3, 받는 피해 −10%. 탑을 깨면 0 으로 돌아감. 보통 난이도에서만 붙음 |
| 도전 단계 | 탑을 깨면 한 단계씩 열림 (최대 6) | 범위 고르기 화면에서 고름. 가장 높은 단계로 깨야 다음 단계가 열림 |

**도전 단계의 규칙** (아래 단계의 규칙이 모두 쌓입니다)

| 단계 | 새로 붙는 규칙 |
| --- | --- |
| 1 | 모든 적의 체력 +15% |
| 2 | 강적 칸이 더 자주 나옴 |
| 3 | 적의 보통 공격 피해 +1 |
| 4 | 힌트 없이 시작, 전투 승리 회복이 절반 |
| 5 | 중간 보스·보스의 체력 +25%, 강한 공격 피해 +2 |
| 6 | 보스전에서는 답을 고르지 않고 **칸에 숫자를 직접 채움** |

숫자는 모두 `js/config.js` 의 `bless`, `cheer`, `ascend` 에 있습니다.

**숫자 칸 채우기 (도전 6단계의 보스전)**

일본 공통테스트의 마크시트처럼, 답의 모양은 보여 주고 숫자 자리만 비워 둡니다. 예: 답이 `3√2/2` 이면 `□√□/□` 가 나오고, 숫자판(0~9, −, 지우기)으로 칸을 채운 뒤 **이 답으로 공격**을 누릅니다.

- 칸은 정답 글의 숫자와 − 부호마다 하나씩 생깁니다. 그래서 `1/2` 와 `0.5` 중 무엇으로 쓸지 고민할 일이 없습니다.
- "필요조건이다"처럼 말로 된 답, 칸이 7개 이상 필요한 답은 평소처럼 보기 4개에서 고릅니다.
- 힌트를 쓰면 칸 하나가 채워집니다.
- 판정과 화면은 `js/battle.js` 의 `makeFill`, `renderFill`, `typeFill` 입니다.

**봇으로 잰 클리어율** (`tools/balance.mjs`, 120판씩. 봇은 행동을 무작위로 고르므로 사람보다 조금 못합니다)

| 정답률 | 선물·격려 없음 (처음 측정) | 지금 | 도전 5단계 |
| --- | --- | --- | --- |
| 50% | 1% | 17% | |
| 60% | 7% | 29% | |
| 70% | 38% | 55% | |
| 80% | 73% | 85% | 41% |
| 90% | 100% | 99% | 86% |

"지금"은 선물, 격려, 몸풀기(1~2층), 4층 휴식 보장, 중간 보스 앞 샘, 보스 공격 조정(보통 5 → 4, 강한 공격 9 → 8)을 모두 넣은 뒤의 값입니다. 도전 5단계는 그 전에 잰 값입니다.
