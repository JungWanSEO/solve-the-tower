# 숫자·문구·몬스터·그림 고치는 법

밸런스 숫자, 화면에 나오는 글, 몬스터, 직접 그린 그림을 바꾸는 방법입니다. 코드를 몰라도 고칠 수 있는 것들을 모았습니다.

[← 처음 문서(README)로 돌아가기](../README.md)

## 6. 숫자 조정하는 법 (밸런스)

| 고치고 싶은 것 | 파일 |
| --- | --- |
| 체력, 피해량, 적의 공격, 골드 보상, 지도 크기, ? 칸의 수치 | `js/config.js` |
| 몬스터별 체력, 약점, 내는 문제 단계 | `data/monsters.json` |
| 강화의 효과, 상점 가격, 칸이 나올 확률 | `js/run.js` |

각 줄 옆에 뜻이 적혀 있습니다. 지금 값은 모두 임시입니다. 직접 해 보고 고칩니다.

**지금 수치의 기준**

자동으로 플레이하는 봇으로 지도 한 장을 여러 번 돌려 본 결과입니다. 봇은 강한 공격 예고 때만 방어하고 나머지는 아무 공격이나 고릅니다. 사람은 이보다 잘합니다.

| 정답률 | 지도 한 장을 클리어하는 비율 |
| --- | --- |
| 90% | 거의 항상 |
| 75% | 4번 중 3번쯤 |
| 60% | 4번 중 1번쯤 |

## 7. 화면 문구 고치는 법

버튼, 안내 문장은 `lang/ja.json`, `lang/ko.json`, `lang/en.json` 에 있습니다. 세 파일은 같은 항목을 가져야 합니다. 한 파일에 항목을 추가하면 나머지 두 파일에도 추가합니다.

## 8. 몬스터 추가하는 법

**지금 있는 몬스터** (모두 학생이 자주 하는 실수를 본떴습니다)

| 몬스터 | 단원 | 뜻하는 실수 | 고유 동작 |
| --- | --- | --- | --- |
| 사코 쌍둥이 | 삼각비 | 사인과 코사인을 바꿔 쓰기 | 둘이 자리를 바꿈 |
| 부호 박쥐 | 삼각비 | 플러스와 마이너스를 틀리기 | 날개의 부호를 뒤집음 |
| 덜약분 골렘 | 삼각비 | 약분하지 않은 답 | 약분되면 작아짐 |
| 괄호 슬라임 | 수와 식 | (a + b)² 의 가운데 항 2ab 빠뜨리기 | 2ab 를 삼킴 |
| 부등호 게 | 수와 식 | 음수로 나눌 때 부등호를 안 바꾸기 | 집게의 부등호가 뒤바뀜 |
| 포물선 유령 | 이차함수 | 꼭짓점의 부호를 반대로 읽기 | 축의 반대쪽으로 넘어감 |
| 뒤죽박죽 막대 (꺼 둠) | 데이터의 분석 | 정렬하지 않고 중앙값 구하기 | 크기 순서로 줄을 섬 |
| 중복 주사위 | 경우의 수와 확률 | 같은 경우를 두 번 세기 | 똑같은 주사위가 하나 더 나타남 |
| 보조선 컴퍼스 | 도형의 성질 | 보조선을 긋지 않고 풀기 | 점선으로 보조선을 그음 |
| 단위 도둑 (중간 보스) | 삼각비 | 단위를 빠뜨리거나 틀리기 | 단위 자루를 들어 올림 |
| 이항 마술사 (중간 보스) | 수와 식 | 이항할 때 부호를 안 바꾸기 | 부호가 그대로인 카드를 넘김 |
| 이상값 거인 (중간 보스, 꺼 둠) | 데이터의 분석 | 이상값에 끌려간 평균을 믿기 | 혼자 뛰어올라 평균선을 올림 |
| 안개 탑 (보스) | 삼각비 | 그림을 그리지 않고 풀기 | 안개로 높이를 가림 |
| 판별식 용 (보스) | 이차함수 | 해가 있는지 확인하지 않고 풀기 | 배의 D 부호가 바뀜 |
| 나머지 생쥐 | 정수 | 몫과 나머지를 바꿔 쓰기 | 치즈의 q 와 r 을 바꿔 듦 |
| 파스칼 삼각바위 | 식과 증명 (数学II) | 이항정리에서 조합만 쓰고 거듭제곱을 곱하지 않기 | 꼭대기부터 숫자가 차례로 밝아짐 |
| 세로셈 톱 | 식과 증명 (数学II) | 나눗셈 세로셈에서 뺄 때 부호를 틀리기 | 톱날이 좌우로 썰림 |
| 허수 도깨비 | 복소수와 방정식 (数学II) | i² 을 1 로 계산하기 | 팻말이 i² = 1 에서 −1 로 뒤집힘 |
| 근과 계수의 거울 | 복소수와 방정식 (数学II) | α + β 의 부호를 반대로 쓰기 | 거울 속 부호가 바뀜 |
| 거리 자 | 도형과 방정식 (数学II) | 좌표의 차를 제곱하지 않고 더하기 | 눈금이 늘어났다 줄어듦 |
| 원 과녁 | 도형과 방정식 (数学II) | 중심의 부호를 반대로 읽기 | 가운데 점이 반대쪽으로 튐 |
| 호도법 시계추 | 삼각함수 (数学II) | 도와 호도를 섞어 계산하기 | 추가 크게 흔들림 |
| 덧셈정리 파도 | 삼각함수 (数学II) | sin(α + β)를 sin α + sin β 로 계산하기 | 물결이 옆으로 흐름 |
| 지수 새싹 | 지수·로그 (数学II) | 지수를 더하지 않고 곱하기 | 줄기가 쑥 자람 |
| 로그 통나무 | 지수·로그 (数学II) | log(M + N)을 log M + log N 으로 계산하기 | 나이테가 구름 |
| 기울기 스케이터 | 미분·적분 (数学II) | 지수를 앞으로 꺼내는 것을 잊기 | 비탈을 미끄러져 내려감 |
| 넓이 양동이 | 미분·적분 (数学II) | x축 아래 넓이를 음수로 답하기 | 물이 찼다 빠짐 |
| 방정식 스핑크스 (중간 보스) | 복소수와 방정식 (数学II) | 해를 하나 찾고 멈추기 | x 가 차례로 떠오름 |
| 미적분 히드라 (보스) | 미분·적분 (数学II) | f′(x) = 0 인 점을 모두 극값이라 단정하기 | 세 머리가 번갈아 치켜듦 |
| 법칙 저울 (중간 보스) | 경우의 수와 확률 | 합의 법칙과 곱의 법칙을 바꿔 쓰기 | 저울이 반대로 기욺 |
| 원의 문지기 (보스) | 도형의 성질 | 정리의 조건을 확인하지 않기 | 삼각형이 원 밖으로 커짐 |

보통 전투, 중간 보스, 보스 모두 **이번 판의 범위에 들어 있는 단원의 몬스터**가 먼저 나옵니다. (`"midboss": true`, `"boss": true` 가 여럿이면 그중에서 고릅니다.) 약점 유형이 범위에 없으면 범위 안에서 하나가 대신 정해집니다.

1. `data/monsters.json` 에 항목을 추가합니다. (`id`, 이름, 뜻하는 실수, 체력, 약점 유형)
2. `js/stage.js` 에 그리는 함수를 하나 만들고 `FOE_DRAW` 에 같은 `id` 로 등록합니다.

그림은 이미지 파일 없이 원, 다각형, 선으로 그립니다. 기존 `drawBat` 을 복사해 고치는 것이 가장 빠릅니다. `"boss": true` 를 넣으면 지도의 마지막 칸에 나옵니다.

## 3-1. 그림을 직접 그린 그림으로 바꾸기

주인공, 몬스터, 장면 그림은 **그림 파일(PNG)로 바꿀 수 있습니다.** 코드는 고치지 않고 `art/` 폴더에 그림을 넣은 뒤 `art/art.json` 에 한 줄을 적습니다. 넣지 않은 것은 지금의 도형 그림이 그대로 나옵니다.

- 방법, 그림 크기와 방향, 몬스터 id 표: [`art/README.md`](../art/README.md)
- 그리는 사람에게 줄 틀: `art/template-monster.png`, `art/template-hero.png`
- 지금 캐릭터의 참고 그림 20장: `art/reference/` (`tools/export-art.mjs` 로 다시 뽑을 수 있음)
- 그림은 한 장이면 됩니다. 흔들림, 돌진, 맞았을 때의 번쩍임, 쓰러짐은 게임이 그 그림에 붙입니다. (`js/stage.js` 의 `sprite`)
