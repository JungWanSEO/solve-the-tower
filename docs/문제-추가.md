# 문제 추가하는 법

단원 파일의 형식, 문제를 만드는 생성기, 그림, 풀이 쓰는 법, 일본어 검수 스크립트를 설명합니다. 문제를 새로 넣거나 고칠 때 봅니다.

[← 처음 문서(README)로 돌아가기](../README.md)

## 5. 문제 추가하는 법

**단원을 꺼 두기**: `data/catalog.json` 의 `off` 에 단원 id 를 적으면 그 단원은 게임에 나오지 않습니다. 범위 고르기, 도감, 연속기, 그 단원의 몬스터가 모두 빠집니다. 파일과 문제는 그대로 남고 검증도 계속하므로, `off` 에서 지우면 바로 돌아옵니다.

**유형 하나만 끄기**: `off` 에 `"단원/유형"` 으로 적습니다. 예: `"off": ["math1-data", "math2-trig/compose"]`. 그 유형의 문제 틀과 그 유형이 들어간 연속기가 함께 빠지고, 범위 고르기와 도감에도 나오지 않습니다. 유형 id 는 단원 파일(`data/units/*.json`)의 `types` 에 있습니다.

지금 꺼 둔 단원: `math1-data` (数学I データの分析). 학교 범위가 아니라는 선생님 확인에 따른 것입니다. 이 단원의 유형 11개, 연속기 2묶음(데이터, 사분위수), 몬스터 2종(뒤죽박죽 막대, 이상값 거인)이 함께 빠집니다. 아래 표에서 꺼 둔 것은 "(꺼 둠)"으로 표시했습니다.

数学I 과 数学A 모두 교과서 차례의 소단원을 넣었습니다. 뺀 것은 4지선다로 물을 수 없는 증명·작도, 표를 찾아 써야 하는 삼각비 표 문제, 서너 단계가 필요한 응용입니다.

문제는 대부분 공식 하나로 풀리는 한 단계 문제입니다. 여러 물음을 이어 푸는 문제는 **연속기**로 나옵니다. 지금 묶음은 22개입니다: 원과 직선(반지름 → 중심에서 직선까지 거리 → 현의 길이), 직선(기울기 → y절편 → x절편), 부채꼴(호도 → 호의 길이 → 넓이), 2배각(cos θ → sin 2θ → cos 2θ), 자릿수(상용로그 → 정수 부분 → 자릿수), 지수방정식(작은 t → 큰 t → x), 삼차함수(f′(x) = 0 의 해 → 극댓값 → 극솟값), 넓이(작은 교점 → 큰 교점 → 넓이), 근과 계수의 관계(두 해의 합 → 곱 → 제곱의 합), 삼차방정식(나머지 → 가장 작은 해 → 가장 큰 해), 이항정리(조합 → 거듭제곱 → 계수), 산술평균·기하평균(두 수의 곱 → 최솟값 → 그때의 x), 대칭식(x² + y² → (x − y)² → x³ + y³), 호제법(나머지 → 최대공약수 → 기약분수의 분모), 이차함수(완전제곱식 → 꼭짓점 → 최댓값), 이차식(판별식 → 방정식의 해 → 부등식의 해), 삼각형(변 → 넓이 → 내접원의 반지름), 직각삼각형(빗변 → sin A → 내접원의 반지름), 확률(경우의 수 → 확률 → 기댓값), 뽑기(뽑아서 세우기 → 뽑기만 → 한 명이 반드시 포함), 원에 내접하는 사각형(마주 보는 각 → 중심각 → 접선과 현의 각), 정수(최대공약수 → 최소공배수 → 곱). 직각삼각형과 원 묶음에는 그림이 붙고, 물음마다 구할 곳이 노란 이름표로 표시됩니다.

**보스 전용 묶음(킬러 묶음)과 검수 중인 묶음**

| 묶음에 적는 값 | 뜻 |
| --- | --- |
| `"boss": true` | 보스전에서만 나오는 어려운 묶음. 보스전의 연속기 버튼은 이 묶음을 먼저 냅니다 |
| `"draft": true` | 아직 검수 중. 평소에는 나오지 않고, 주소 끝에 `?draft=1` 을 붙여 열었을 때만 (어느 전투에서든, 다른 묶음보다 먼저) 나옵니다 |

지금은 예시가 하나 있습니다: 数学I 二次関数의 `chain-killer` (문자 a가 든 이차함수: 꼭짓점 → 최솟값 m의 최댓값 → 최솟값이 정해진 값이 되는 a). 선생님 검수를 받는 중이라 `draft` 가 켜져 있습니다. 검수가 끝나면 `"draft": true` 한 줄을 지우면 보스전에 나옵니다.

문제는 `data/units/<단원>.json` 에 있습니다. **문장 틀**과 **숫자 묶음**으로 나뉘어 있어서, 숫자만 다른 문제는 한 줄만 추가하면 3개 언어로 모두 나옵니다.

**숫자만 다른 문제 추가**

해당 틀의 `items` 에 한 줄을 더합니다.

```json
{ "d": 20, "deg": 45, "answer": "20 m", "wrong": ["10√2 m", "22 m", "10 m"] }
```

- `answer`: 정답
- `wrong`: 오답 보기 3개. 정답과 겹치면 안 됩니다.
- 나머지(`d`, `deg` 등): 문장 틀의 `{d}`, `{deg}` 자리에 들어갈 값

**새로운 종류의 문제 추가**

`templates` 에 틀을 하나 더합니다.

| 항목 | 뜻 |
| --- | --- |
| `id` | 틀의 이름 (영문, 겹치지 않게) |
| `level` | 1 = 개념 확인, 2 = 계산, 3 = 응용 |
| `type` | 유형. 파일 위쪽 `types` 에 있는 이름이어야 합니다 |
| `text` | 문제 문장. ja, ko, en 세 가지를 모두 씁니다 |
| `explain` | 틀렸을 때 보여줄 해설 한 줄 |
| `items` | 숫자 묶음 목록 |

**숫자를 자동으로 만드는 문제**

틀에 `items` 대신 `"gen": "<이름>"` 을 적으면 `js/generators.js` 의 생성기가 매번 새 숫자를 만듭니다. 오답 보기는 "사인 대신 코사인을 쓴 값"처럼 흔한 실수에서 나오는 값으로 만들어집니다.

새 생성기를 추가할 때는 답이 깔끔하게 떨어지는 숫자만 쓰도록 하고, 정답과 값이 같은 오답이 생기지 않게 `item()` 과 `choose()` 를 그대로 씁니다.

**문제에 그림 붙이기**

틀에 `figure` 를 적으면 그 틀의 모든 문제에 그림이 붙습니다. 숫자는 `items` 에서 자동으로 들어갑니다.

```json
"figure": { "kind": "triangle", "angle": "θ", "opp": "{a}", "adj": "{b}", "hyp": "{c}" }
```

| kind | 그림 | 적을 수 있는 자리 |
| --- | --- | --- |
| `triangle` | 직각삼각형 | `angle` 각, `opp` 맞은편 변, `adj` 이웃 변, `hyp` 빗변 |
| `tower` | 탑 하나 | `angle` 올려본 각, `dist` 수평거리, `height` 높이 |
| `twopoint` | 탑과 두 지점 | `far` 먼 지점의 각, `near` 가까운 지점의 각, `gap` 두 지점 사이, `height` 높이 |
| `anytri` | 삼각형 ABC | `angleA` `angleB` `angleC` 각, `sideA` `sideB` `sideC` 변 (a는 A와 마주 보는 변) |

구해야 하는 자리에는 `"?"` 를 적습니다. 표시하지 않을 자리에는 `""` 를 적습니다.

**어느 단계가 어디에 나오나**

| 단계 | 나오는 곳 |
| --- | --- |
| 1 | 기본 공격, 방어, 휴식의 복습 |
| 2 | 스킬, 보물, ? 칸의 석상, 보스의 기본 공격 |
| 3 | 보스의 스킬 |

**문제의 조건 적기** (`note`)

답을 내는 데 필요한 약속은 문제 문장에 섞지 않고 `note` 에 따로 적습니다. 화면에서는 문제 아래에 노란 점선 상자로 "조건: …" 이 나옵니다.

```json
"note": { "ja": "x は実数とする。", "ko": "x는 실수이다.", "en": "x is a real number." }
```

이런 것을 적습니다: 수의 범위(x 는 실수, x ≠ 0), 근삿값(원주율은 3.14 로 계산한다), 무시할 것(눈높이는 생각하지 않는다), 계산 방식(분산은 n 으로 나눈다), 같은 것으로 보는 기준(돌려서 같으면 같은 배열). 문제의 숫자를 넣을 수도 있습니다. (`"x ≠ {a}"`)

**보기가 말인 문제** (`@이름`)

보기가 숫자나 식이 아니라 말이면, 생성기에서 보기를 `"@suf"` 처럼 적고 세 언어 파일의 `opt` 에 문구를 둡니다. 필요조건·충분조건 문제가 이렇게 되어 있습니다. 보기가 길면 답 버튼이 자동으로 한 줄에 하나씩 놓입니다.

**그림 붙이기** (`figure`)

도형 문제에는 그림이 꼭 있어야 합니다. 틀에 `figure` 를 적으면 문제의 숫자가 그림에 들어갑니다. 구하는 값은 `"BD = ?"` 처럼 `?` 를 넣어 적으면 노란 이름표가 됩니다.

| kind | 그림 | 적는 값 |
| --- | --- | --- |
| `triangle` | 직각삼각형 | angle, opp, adj, hyp |
| `tower`, `twopoint` | 탑과 관측 지점 | angle, dist, height / far, near, gap, height |
| `anytri` | 삼각형 ABC | angleA~C, sideA~C |
| `bisect` | 각의 이등분선 | ab, ac, bc, bd |
| `median` | 중선과 무게중심 | am, ag |
| `incenter` | 내심 | angleA, bic |
| `circleangle` | 원주각과 중심각 (외심) | central, insc, names, chord |
| `cyclic` | 원에 내접하는 사각형 | angleA, angleC |
| `chords` | 원 안에서 만나는 두 현 | pa, pb, pc, pd |
| `tangent` | 할선과 접선 | pa, pb, pt |
| `cuboid` | 직육면체 | ab, ad, ae, ag |
| `space` | 두 지점에서 본 탑 (∠AHB = 90°) | angleA, angleB, ab, ph |
| `incircle` | 삼각형과 내접원 | ab, bc, ca, r 또는 af |
| `ceva` | 체바의 정리 | af, fb, bd, dc, ce |
| `tanchord` | 접선과 현 | acb, bat |
| `grid` | 격자 길 | cols, rows |
| `histogram` | 히스토그램 | freq, from, step |
| `boxplot` | 상자그림 | five |
| `scatter` | 산포도 | pts |
| `tetra` | 정사면체 | edge, h |
| `menelaus` | 메넬라우스의 정리 | ar, rb, bp, cq |

도형 그림 아래에는 "그림은 실제 길이·각도와 다르게 그려져 있습니다" 가 자동으로 붙습니다. (통계 그래프와 격자 길은 정확한 그림이라 붙지 않습니다.) 새 그림은 `js/figures.js` 의 `DRAW` 에 추가합니다.

**연속기 묶음 추가하기** (`chains`)

단원 파일에 `templates` 와 나란히 `chains` 를 둡니다. 공통 지문(`intro`)과 물음 목록(`steps`)으로 이루어집니다.

```json
"chains": [{
  "id": "chain-quad", "gen": "quad",
  "intro": { "ja": "関数 {f} について答えよ。", "ko": "함수 {f}에 대하여 답하시오.", "en": "…" },
  "steps": [
    { "type": "complete", "level": 2, "sum": { "ko": "완전제곱식", … }, "text": { … }, "explain": { … } },
    { "type": "vertex", "level": 1, "sum": { "ko": "꼭짓점", … }, "text": { … }, "explain": { "ko": "{a1}에서 꼭짓점은 {answer}", … } }
  ]
}]
```

| 항목 | 뜻 |
| --- | --- |
| `gen` | `js/generators.js` 의 `CHAINS` 에 있는 생성기 이름. 숫자 묶음 하나에서 물음별 정답과 오답을 한꺼번에 만듭니다 |
| `intro` | 모든 물음 위에 계속 보이는 공통 지문 |
| `figure`, `note` | 묶음 전체에 붙는 그림과 조건 (물음마다 `note` 를 따로 줄 수도 있습니다) |
| `steps[].type` | 그 물음의 유형. 도감에는 이 유형으로 기록됩니다. 묶음의 유형이 모두 범위에 있어야 그 묶음이 나옵니다 |
| `steps[].sum` | 풀고 난 뒤 한 줄 요약에 쓰는 이름. 예: "(1) 꼭짓점: (2, −1)" |
| `{a1}`, `{a2}` | 앞 물음의 정답. 뒤 물음의 문장과 해설에 쓸 수 있습니다 |

피해량은 `js/config.js` 의 `damage.chain` 입니다.

**단원 추가하기**

1. `data/units/` 에 단원 파일을 만듭니다. (기존 `math1-trig.json` 을 복사해 고치면 됩니다.)
2. `data/catalog.json` 의 해당 과목 `units` 에 파일 이름을 추가합니다. 과목이 없으면 과목도 추가합니다.
3. 범위 고르기 화면과 도감에 저절로 나타납니다.

단원 파일의 `groups` 는 범위 고르기 화면에서 유형을 묶어 보여주는 소제목입니다.
